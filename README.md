# TP2 - Organización Empresarial - Análisis de Ventas

## Integrante
- Hernán Bula (simulando roles P1, P2, P3)

## Escenario elegido
B - Análisis de Ventas de una Pequeña Empresa

## Dataset
Se utiliza un archivo CSV de ventas con columnas: id, fecha, importe.

## Estructura del proyecto
- `/datos`: contiene el dataset.
- `/scripts`: contiene el script de análisis.
- `/resultados`: contiene resumen.txt y gráfico.png.

## Cómo ejecutar
1. Clonar el repositorio.
2. Ubicar el CSV en `/datos`.
3. Ejecutar `python scripts/analisis.py`.
